## 背景

- floorplan 的 `ADR-业务口径总定源.md` **Q15 定源「日本征信报送：外部合规，本轮不接」**；
  `外部集成接口文档 §4.4` 只设计了查**企业/经销商**信用且标【预设】、零代码；
  `十一环节闭环核查报告:97`「无征信表、无接口，一期人工录入评级，属有意边界」。
- 本项目是 C 端个人信用业务，**征信对接是刚性需求**，且已核实：
  - CIC 同时是**分期付款销售法与贷金业法**下的指定信用信息机构；
  - 分期付款销售法下个别信用购买斡旋业者负**个别支付能力预估额**调查义务；
  - 贷金业法下面向个人的贷款业者**必须加入**指定信用信息机构、查询总借入余额，并在契约/变更时提供个人信用信息。
  ⟹ 无论 `C-01` 裁定为哪种形态，查询 + 登记 + 异议都是必接链路（`R01 §2.4`）。
- 征信局接入需**审查 + 专用线路 + 固定报文**，周期长、费用按次、报文与 DPD 口径需按机构重定源。
- 若让业务模块直接调征信局，会把外部编码、报文格式、故障语义渗进领域模型。

## 结论

1. 设立**独立防腐上下文 BC-4「征信集成 / Bureau Gateway」**，作为**唯一**对接征信局的出口/入口。
   业务模块不直接调用征信局，只通过内部 Command / 事件交互。
2. **三条链路**：
   - **查询**：审查前，须 `Consent` 有效（INV-5）→ `CreditInquiry` 留痕（时间/机关/用途/同意 ID/结果摘要/费用）→ 结果落**快照**，不重算历史；
   - **登记/更新**：合同内容/还款状况 T+1 报送，`integration.credit_bureau_reports` 留痕，可人工重触发；
   - **异议申诉 / 查阅 / 更正**：`integration.bureau_disputes` 工单，SLA 由 `[待定源 C-05]` 定，处理留痕 + 订正报送。
3. **外部 DTO 必经 ACL**：机构报文 → `BureauAdapter`（字段映射 + 枚举翻译）→ 内部 `Command`。
   机构编码（异议标记等）不进入 `domain`。
4. **同意是硬前置**：`credit_inquiries.consent_id` / `credit_bureau_reports.consent_id` 非空（DB 约束 + INV-5）；
   `CONSENT_WITHDRAWN` 秒级广播阻断后续查询与报送（RB-1）。
5. **接入未审批前的降级**：`BureauAdapter` 提供「人工查询 + 结果录入 + `source=MANUAL`」正式通道，
   与自动通道汇入同一 Command；**不写空结果、不留假 `INQUIRY_DONE`**。
6. 报送口径（机构组合、报文、周期、DPD 映射）由 `CreditBureauReportingPolicy` 承载，
   标 `[待定源 C-05]`，**不沿用 floorplan 的「国内口径」**。

## 后果

**变容易**：征信局审查周期/报文变更只影响一个 Adapter；同意留痕可审计；人工路径与自动路径等价；
形态反转（`ADR-RF-002`）只需换 `CreditBureauReportingPolicy` 实现。

**变难**：多一跳间接层；机构报文与内部模型的映射需要维护；查询费用与频率要控制；
「异议申诉」跨机构工作流复杂，SLA 按 C-05 AI 裁决 30 日实现（可配），法定时限待核实。

**明确不做**：不把征信结果直接写进 `Application` / `Loan`；不缓存征信结果到 Redis；
不在未取得同意时查询；不把人工录入说成「已接征信局」；不在 S0 假定接入已审批。

## 被拒选项与理由

| 选项 | 理由 |
|---|---|
| 沿用 floorplan Q15「本轮不接征信」 | C 端业务的法定/业务刚性需求，且与分期付款销售法/贷金业法义务冲突 |
| 各业务模块直接调征信局 API | 外部编码与故障语义污染领域模型，违反 P-8（外部必经 ACL） |
| 把征信结果作为 `Loan` 的字段 | 查询是审查时点快照，必须 append-only 可追溯，不能覆盖历史 |
| 只做查询、不做登记/异议 | 报送与异议是同法域下的义务链，缺一即合规缺口 |
| 机构未审批就用挡板刷绿 | 假绿；公司反模式明确禁止把占位说成已实现 |

## 权衡

放弃「业务模块直连机构最快」，换取**外部变化隔离、同意可审计、形态可替换**。
征信局是本项目周期最长、最不可控的外部依赖，值得为它单独设一道防腐层。
