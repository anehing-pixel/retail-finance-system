## 1. 引用口径

- 阶段 **S0–S4**、工作包 **W1–W8**、需求/断言编号沿用 `R01`/`R10`，不另起体系。

- 「工作包」= 可独立交付的服务/能力集合；「并行窗口」= 互不共享写入集的服务组合。
- 实时状态以 `PROGRESS.md` 为准，本文件的勾选不随开发更新。
- 全文中文；服务名、表名、枚举、配置键保留英文标识符。

## 4. 并行窗口与跨项目节奏协调

### 4.1 内部并行窗口（多服务）

```
W1(串行) → W2(串行，冻结契约/号段/路由)
   → ┬─ W3：customer-service + application-service（独占 pii.* / applications / dealer_partners）
     ├─ W4：underwriting-service + bureau-service（独占 underwriting_* / credit_inquiries / 报送表）
     └─ W5：contract-service + retail-core 前半（独占 contracts / loans / disbursements）
   → W6(串行，账务事务红线 + title-release-service)
   → W7(servicing / recon / 合规横切) → W8(收口)
```

**四处硬耦合（决定边界）**：
1. 共享层已有类（`common` / `application` 端口 / `OutboxPublisher` 事件名常量表）只能单 owner，跨包修改走 W1 或 W8。
2. `PROGRESS.md` / `AGENTS.md` / 父 `pom.xml` / `gateway/application.yml` / `run-microservices.sh` / `scripts/*`
   是**共享禁区**（`AGENTS §7`）。
3. Flyway 号段 V1–V9 由 W2 统一建，后续包**只新增 V10+**，不得改已执行脚本。
4. **Feign 契约与事件名**由 W2 冻结在 `common/contract`；并行包只能消费、不得自行新增未登记契约。

**每包独占写入集**：服务模块目录 + 自己的表组 + 自己的冒烟脚本 + 自己的网关路由段（路由段由 W2 预分配，
并行包只填自己那一段，避免同时改同一个 yml）。

### 4.2 与 floorplan 的协调（同公司）

| 事项 | 规则 |
|---|---|
| 中台 jar 抽取 | W1 **新增 artifact**，floorplan 不改包；发布前后各跑一次 floorplan 全量构建 + 冒烟，证明基线未破坏 |
| 版本 | 语义化版本；不兼容变更大版本 + 双方评审 + 各自锁定（`R03 §6.2`） |
| 共享资源 | 端口段 / 号段 / 前缀 / 密钥 / Feign 契约在 `PROGRESS §2` 登记，双方只读 |
| 销售店主数据 | floorplan 是权威写者；RF 由 `application-service` 做**唯一只读投影**，同步失败降级人工（`ADR-RF-010`） |
| 架构形态 | 两仓同为 Spring Cloud 微服务；网关切流、精确装配、outbox、Feign 门禁、冒烟走网关的范式共用 |
| 文档范式 | 两仓共用「文档控制 + 引用口径 + 自检」三节与四状态标；本仓 ADR 收进 `docs/adr/` 的偏离已在 `R00 §8` 登记 |
| 禁止 | 不共享数据库实例、不共享 JWT 密钥、不 import 对方包、不平移对方已裁决口径 |
